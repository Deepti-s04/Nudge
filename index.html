Nudge Privacy Policy

Last updated: October 16, 2026

Nudge is a Chrome extension designed to help users manage distractions, block selected websites, and track focus sessions.

Information Used

Nudge stores user-selected blocked and restricted website domains, focus session state, website usage durations, and session history to provide its features.

How Information Is Used

This information is used to enforce website restrictions, calculate website usage durations, and display focus analytics in the extension dashboard.

Storage and Sharing

Nudge uses Chrome extension storage for its settings and tracking data. The developer does not sell users' personal information. Before publishing, the developer must verify and accurately disclose whether any data is transmitted to external servers or third-party services.

Permissions

Nudge uses storage, tab information, and website access as needed for its focus timer, website blocking, and usage tracking features.

Data Retention and Deletion

Users can remove website settings and session data through available extension controls. Removing the extension also affects its locally stored Chrome extension data.

Contact

For privacy questions, contact the developer using the public contact email listed on the Nudge Chrome Web Store listing.
